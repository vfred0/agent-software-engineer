== Introducción

Este repositorio contiene una colección de habilidades (skills) para agentes de inteligencia artificial (IA) en el ámbito del desarrollo de software. Cada habilidad está diseñada para proporcionar a los agentes de IA la capacidad de realizar tareas específicas relacionadas con el diseño, desarrollo, pruebas y documentación de software.

== Estructura de Directorios en Agentes de IA

Para que un agente funcione correctamente, debe seguir una estructura de directorios específica. A continuación se muestra un ejemplo de cómo organizar los archivos y directorios dentro de un agente de IA:

== Instalación

Copiá las skills al directorio de configuración del agente que usás en tu proyecto.
Ejecutá el comando desde la raíz de tu proyecto destino.

[source,bash]
.Claude Code (.claude/)
----
mkdir -p ~/.claude/skills
cp -r ./{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer,version-control,ci-cd,ansible} ~/.claude/skills/
----

[source,bash]
.Gemini CLI (.gemini/)
----
mkdir -p ~/.gemini/skills
cp -r ./{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer,version-control,ci-cd,ansible} ~/.gemini/skills/
----

[source,bash]

----
mkdir -p ~/.github/skills
cp -r ./{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer,version-control,ci-cd,ansible} ~/.github/skills/
----

[source,bash]

[source,bash]
.Windsurf (.windsurf/)

cp -r ./{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer,version-control,ci-cd,ansible} ~/.windsurf/skills/

[TIP]
====
Reemplazá `/path/to/agent-software-engineer/` con la ruta absoluta a este repositorio.
Para copiar skills individuales, simplemente omitís las que no necesitás del bloque `{}`.
====
