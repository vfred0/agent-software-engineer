== Introducción

Este repositorio contiene una colección de habilidades (skills) para agentes de inteligencia artificial (IA) en el ámbito del desarrollo de software. Cada habilidad está diseñada para proporcionar a los agentes de IA la capacidad de realizar tareas específicas relacionadas con el diseño, desarrollo, pruebas y documentación de software.

== Estructura de Directorios en Agentes de IA

Para que un agente funcione correctamente, debe seguir una estructura de directorios específica. A continuación se muestra un ejemplo de cómo organizar los archivos y directorios dentro de un agente de IA:

[source,text]
----
./AGENT_NAME/ -> claude, gemini, copilot, opencode, etc
└── skills/
    ├── documentation-generator/
    │   ├── SKILL.md
    │   └── src/
    │       ├── *.example.puml
    │       └── utils/
    ├── software-design/
    │   ├── SKILL.md
    │   ├── architecture.md
    │   ├── design.md
    │   ├── modular.md
    │   ├── oop.md
    │   └── patterns.md
    ├── software-testing/
    │   ├── SKILL.md
    │   ├── software-testing.md
    │   ├── unit-testing.md
    │   ├── unit-testing-test-cases.md
    │   └── unit-testing-test-doubles.md
    └── software-engineer/
        ├── SKILL.md
----

== Instalación

Copiá las skills al directorio de configuración del agente que usás en tu proyecto.
Ejecutá el comando desde la raíz de tu proyecto destino.

[source,bash]
.Claude Code (.claude/)
----
mkdir -p .claude/skills
cp -r /path/to/agent-software-engineer/{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer} .claude/skills/
----

[source,bash]
.Gemini CLI (.gemini/)
----
mkdir -p .gemini/skills
cp -r ./{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer} .gemini/skills/
----

[source,bash]
.GitHub Copilot (.github/)
----
mkdir -p .github/skills
cp -r /path/to/agent-software-engineer/{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer} .github/skills/
----

[source,bash]
.OpenCode (.opencode/)
----
mkdir -p .opencode/skills
cp -r /path/to/agent-software-engineer/{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer} .opencode/skills/
----

[source,bash]
.Cursor (.cursor/)
----
mkdir -p .cursor/skills
cp -r /path/to/agent-software-engineer/{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer} .cursor/skills/
----

[source,bash]
.Windsurf (.windsurf/)
----
mkdir -p .windsurf/skills
cp -r /path/to/agent-software-engineer/{software-engineer,software-design,software-testing,documentation-generator,spring-boot-developer} .windsurf/skills/
----

[TIP]
====
Reemplazá `/path/to/agent-software-engineer/` con la ruta absoluta a este repositorio.
Para copiar skills individuales, simplemente omitís las que no necesitás del bloque `{}`.
====
