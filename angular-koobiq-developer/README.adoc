== Notas Importantes

- Toda la documentación está basada en el código real del proyecto, no se deducen comportamientos.
- Se usa Kobiq Components (`@koobiq/components`) como librería de UI.
- La gestión de estado reactivo usa Angular Signals (`signal`, `computed`, `WritableSignal`).
- Las operaciones asíncronas usan el patrón `Operation` basado en RxJS y Signals.
